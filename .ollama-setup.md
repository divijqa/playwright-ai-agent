Ollama setup for Jenkins

This project uses Ollama as the local LLM backend. For CI (Jenkins) you must ensure Ollama is running and the required model is downloaded.

1. Install Ollama on the Jenkins host per https://ollama.com/docs

2. Pull the required model (run as the user Jenkins runs as or ensure permissions):

```
ollama pull qwen2.5-coder:7b
```

3. Ensure Ollama API is reachable at the default local address. The Jenkins process must be able to reach:

```
http://127.0.0.1:11434
```

If Ollama runs on another host/container, set the environment variable in Jenkins:

```
OLLAMA_BASE_URL=http://ollama-host:11434
```

Notes:
- The project currently pins to `qwen2.5-coder:7b`. In a later v1.5 update we plan to migrate to MCP models; no action required now.
- Use `OLLAMA_MODEL` to override the model name if needed (example: `qwen2.5-coder:7b`).
- The Jenkins pipeline will set `TEST_SERVER_PORT` to avoid port conflicts; adjust as needed.
